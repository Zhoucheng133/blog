## 将元素放置于页面中间

```css
.content{
  width: 100px;
  height: 100px;
  background-color: blue;
}
body{
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
  margin: 0;
}
```


### 水平居中

```css
margin: 0 auto;
```

如果是`fixed`或者`absolute`布局，可以这样写：

```css
left: 50%;
transform: translateX(-50%);
```

### 垂直居中

一般来说使用`flex`布局来实现

如果是`fixed`或者`absolute`布局，可以这样写：

```css
top: 50%;
transform: translateY(-50%);
```

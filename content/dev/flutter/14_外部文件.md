## 添加外部文件

需要在文件`pubspec.yaml`中添加：

```yaml
flutter:
  assets:
  # 这里添加你的外部文件夹，这里以根目录/assets举例
    - assets/
```

## 显示图片

### 系统文件

```dart
// 使用本地路径的图片
return Image.file(File(filePath));
```

### assets图片

```dart
// 使用assets配置目录下的图片
return Image.assets("/assets/xxx.jpg");
```

### 网络图片

```dart
return Image.network("https://xxx.jpg");
```

## 修改缓存大小

> [!NOTE]
> 如果图片尺寸很大并且数量很多，如果直接显示可能会导致占用过多内存

```dart
return Image.assets(
  "/assets/xxx.jpg",
  cacheWidth: /** 限制图片缓存的宽度 */,
  // 或者使用cacheHeight
);
```
